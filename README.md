## ✨ Features

- 🎬 **YouTube to MP3 Conversion** - Convert your favorite YouTube videos to MP3 format
- 📱 **Offline Playback** - Listen to your music without internet connection
- 🎨 **Modern UI** - Clean and intuitive retro-inspired interface
- 🎵 **Music Player** - Built-in player with essential playback controls
- 📂 **Library Management** - Organize and manage your downloaded tracks
- 🌙 **Dark Mode** - Easy on the eyes with a sleek dark theme
- ⚡ **Fast & Efficient** - Quick downloads and smooth performance

## 🚀 Installation

### Prerequisites

- Flutter SDK (3.0 or higher)
- Dart SDK
- Android Studio or VS Code
- Android device or emulator (Android 5.0+)

### Build from Source

1. **Clone the repository**
   ```bash
   git clone https://github.com/bargaouiahmed/Retrosica.git
   cd Retrosica/retrosicav2
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the app**
   ```bash
   flutter run
   ```

4. **Build APK**
   ```bash
   flutter build apk --release
   ```

## 📖 Usage

1. **Launch the app** on your Android device
2. **Search or paste** a YouTube video URL
3. **Select the video** you want to convert
4. **Download** and convert to MP3
5. **Enjoy** offline playback in your library

## 🛠️ Technologies

- **[Flutter](https://flutter.dev/)** - Cross-platform UI framework

- **[just_audio](https://pub.dev/packages/just_audio)** - Audio playback
- **[audio_service](https://pub.dev/packages/audio_service)** - Background audio handling
- **[sqflite](https://pub.dev/packages/sqflite)** - Local database
- **[path_provider](https://pub.dev/packages/path_provider)** - File system access
